# CivTrack

CivTrack is a centralized web platform designed to help communities report and track municipal issues. The goal of the project is to provide residents with an easy way to submit issues while giving administrators a centralized system for managing and monitoring reports.

## Project Overview

CivTrack was developed as a software engineering project at Lawrence Technological University. The project was developed using an Agile development approach and was completed as a team project.

The platform allows users to report municipal issues and provides a system for organizing and managing those reports.

## Features

- Submit reports for municipal issues
- Store and manage issue reports in a centralized database
- Track reported issues
- Web-based user interface
- Backend API for handling application functionality
- Database integration for persistent data storage
